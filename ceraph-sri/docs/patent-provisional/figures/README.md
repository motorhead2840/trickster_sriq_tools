# Landscape patent figures (downloadable)

Left-to-right Mermaid renders for Google Docs / Word (**use landscape page**).

## Quick download

- **All files:** [sri-patent-figures-landscape.zip](sri-patent-figures-landscape.zip)
- Or download individual `fig-0N-*.png` / `.svg` in this folder

## Regenerate

From repo root (requires network for npx once):

```bash
bash docs/patent-provisional/figures/render-landscape.sh
```

Source diagrams: `*.mmd` here and `../03-mermaid-architecture-diagrams.md`.
