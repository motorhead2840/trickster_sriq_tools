   Why the high-SNR curves are flat: each tile observes y_n = τ_n ψ + w_n with the *same* unknown ψ. Least-squares on any connected graph recovers η + ε, so the residual does not accumulate along long paths. This is a different measurement model from Barooah–Hespanha, whose theorems assume *independent* noise on each edge.

WHAT THIS DOES NOT SHOW
=======================
- This is a classical numerical simulation of complex arrays. Using i and a Hilbert-space notation for a veil does not make the simulation quantum, and it does not demonstrate entanglement, a quantum advantage, or a new physical chip.
- There is no CMOS, timing-error, voltage, or energy model here. The notebook does not compare a tile array to Razor-style detection or adaptive voltage scaling. That measured-result claim still needs an FPGA or ASIC experiment.
- This is not a theorem. The N-scaling we fit is empirical over a modest range of N. The LS theory on graphs with independent edge noise is already known (Barooah & Hespanha). What would be new is a theorem about unveiling without a reference under the *shared-input* (or partial-overlap) model — including a precise statement of when the coboundary structure holds and when topology takes over.
- The main model gives every tile the same K samples ψ_k. If neighboring tiles never process related inputs, the ratio r_nm is not an estimate of τ_n/τ_m, and the method as written does not apply. A careful partial-overlap model (neighboring tiles sharing a window of a data stream) is left for a later notebook.
- A programming model in which the programmer declares Ξ_crit(c) is not implemented here.
- The local Jacobi / phase-sync iteration on a ring needs many more than a few hundred steps to reach the LS/eigenvector solution (see the convergence diagnostic). The scaling plots report that *converged* decentralized estimator, not a short iteration.
